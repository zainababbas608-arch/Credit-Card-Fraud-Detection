# Dataset — IEEE-CIS Fraud Detection

Download the dataset from [Kaggle](https://www.kaggle.com/c/ieee-fraud-detection/data) (requires a free Kaggle account) and place the CSV files in this folder:

- `train_transaction.csv` (~650 MB)
- `train_identity.csv` (~25 MB)
- `test_transaction.csv` (~585 MB)
- `test_identity.csv` (~25 MB)
- `sample_submission.csv` (~6 MB)

> **Note:** Raw CSVs are intentionally NOT committed to git — they exceed GitHub's
> 100 MB file limit. See `.gitignore` at the repo root.
