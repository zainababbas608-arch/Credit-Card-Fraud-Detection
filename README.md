# Credit Card Fraud Detection (IEEE-CIS) - Big Data Analytics

End-to-end fraud-detection system: batch pipeline + officer dashboard + streaming tier.
PySpark inside Docker; a single champion model (GBT, threshold 0.5) feeds both the
replay dashboard and the Kafka streaming alert monitor.

## Layout
- `notebooks/`       - the pipeline, in order: 01 ingests, 02 EDA, 03-04 prep + features,
                       05 model shootout, 06 full-scale training, 07 streaming preview
- `src/dashboard/`   - officer dashboard (Streamlit, replay + live feed)
- `src/stream/`      - producer (test transactions -> Kafka) + headless streaming job
- `data/`            - not in git: raw CSVs / processed parquet / stream runtime (see data/README.md)
- `models/`          - saved champion model (not in git)
- `reports/`         - evidence screenshots (NN_short_name.png) + figures

## How to run
1. Docker Desktop up, then open the project in VS Code and reopen in the container.
2. Data + model artifacts are regenerated by notebooks 01-06 (~1.6 GB on disk).
3. Dashboard:            .\run_dashboard.ps1          (replay mode)
   Full live tier:       .\run_dashboard.ps1 -Live   (kafka + stream job + producer)
   Shut them down:       .\run_dashboard.ps1 -Stop
4. Session start/end discipline: Docker Desktop -> VS Code "Reopen in Container" -> work;
   shut down: stop kernels, quit VS Code, quit Docker Desktop.
